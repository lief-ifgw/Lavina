# Lavina
  Iniciado em 2020, o Projeto LAVINA é uma tentativa direta de democratização do acesso do lado lúdico e interativo da física. Nós temos o compromisso de fornecer um apoio ao aprendizado de física através da simulação de experimentos em uma plataforma online acessível de forma completamente gratuita. 

Esta página tem como objetivo fornecer um apoio ao aprendizado de física através da simulação de experimentos em uma plataforma online. Essas simulações serão feitas visando um resultado parecido ao de physlets, utilizando JavaScript puro sempre que possível para as dinâmicas de cada simulação.
